# Ako Centric CRM

Admin and trainer CRM for Ako Centric: leads, attendance, enrollment, schedules, trainer hours, lesson plans, invoices and certificates.

- Static site (index.html) deployed on Vercel.
- Data, sign-in and lesson documents in Supabase (project "HPR (Voting)", tables prefixed `ako_`).
- Staff accounts are managed in the app under Settings (edge function `ako-staff`).
